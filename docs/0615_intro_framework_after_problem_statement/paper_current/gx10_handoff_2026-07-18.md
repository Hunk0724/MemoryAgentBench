## 情況同步(Mac 側 2026-07-17→18 進展)

### 1. Subject-consistency guard 是什麼

`methods/phase2_query.py:146-151` `_subject_consistent()` —— 於 P3 LLM identity clustering(`llm_identity_clusters`)後對每個 cluster 執行 **post-filter**:若 cluster members 有 ≥2 個 distinct KNOWN subject(從 `metadata.triple.subject_id` 或 `subject_fallback` 讀取)→ **整群 REJECT**。

Guard 與 GROUPING_PROMPT 的 HARD RULE 1(「別合併不同 subject」)是**兩層獨立機制**:prompt 是 LLM 側 soft guidance(LLM 常違背),guard 是 Python 側 hard post-filter(必然執行)。

### 2. Mac 側完成的 audit + ablation

**離線 audit(2026-07-17)**:於 gpt-4o-mini 4 length,guard reject 掉 LLM 提議的 **54-67%** clusters —— 高活性,非 rare edge case。

**實跑 ablation(2026-07-17)**:新增 env var `MEM0_SUBJECT_GUARD_OFF=1` bypass guard;於 canonical `ours_no_p5` reuse 同 store + cache,僅 query-time 改變 → 對比 EM:

|:--|:-:|:-:|:-:|

| FC-SH 32k | 91 | 88 | **−3** ⚠ |

**FC-SH mean 4L guard-off 淨好 +1.5pp**;LME 微降 1 題(noise range)。兩 benchmark 加權後 **Δ ≈ 0-1pp,不明確**。

### 3. 於其他 backbone 的離線 predictor 結果

**Predictor 公式**:`Predicted Δ_guard-off = touch_BOTH(guard 誤傷)− touch_gt_new_alone(guard 有救)`

### 任務 B(若有 cache,~5 min wall,零成本):跑離線 predictor

於 GX10 上執行下面的 Python(參 Mac 側 audit 邏輯,mirror `analysis/attribute_sp_merge_6k.py` normalization):

```python
import json, os, re, hashlib
def _fk(f): return hashlib.sha256(f.strip().encode("utf-8")).hexdigest()
def ns(s):
    if s is None: return None
    s = s.lower().strip(); s = re.sub(r"[-‐-―]"," ",s); s = re.sub(r"\s+"," ",s).strip()
    if s in {"user","i","me","my","myself"}: return "user"
    if s in {"assistant","you","claude","agent"}: return "assistant"
    return re.sub(r"\s+","_",s)

gt = json.load(open("analysis/results/sh_512_mquake_analysis.json"))
gt_hp = {r["query_id"]: r for r in gt if r.get("conflict_type")=="has_pair"}
new_texts = {(r.get("gt_fact_text") or "").strip().rstrip(".").lower() for r in gt_hp.values()}
old_texts = {(r.get("old_fact_text") or "").strip().rstrip(".").lower() for r in gt_hp.values()}

for backbone in ["gemma3-1b","gemma3-4b","gemma3-12b","gemma3-27b",
                 "gemma2-9b","llama3.1-8b","qwen2.5-7b","mistral-7b"]:
    base = f"analysis/results/p1_caches__{backbone}"
    tp = f"{base}/triple_cache_p1_6k.json"; sp = f"{base}/subject_cache_p1_6k.json"
    gp = f"{base}/grouping_cache_no_p5_6k.json"
    if not (os.path.exists(tp) and os.path.exists(gp)):
        # try grouping_cache_p3_only as fallback (used for ours_p3_only_no_struct)
        gp = f"{base}/grouping_cache_p3_only_6k.json"
    if not (os.path.exists(tp) and os.path.exists(gp)):
        print(f"{backbone:<15}: MISSING (need at least triple+grouping)"); continue
    tc = json.load(open(tp))
    sc = json.load(open(sp)) if os.path.exists(sp) else {}
    gc = json.load(open(gp))
    n_c = n_rej = n_save = n_hurt = 0
    for qk, groups in gc.items():
        for group in groups:
            n_c += 1
            subs = []
            for fact in group:
                k = _fk(fact); e = tc.get(k)
                if isinstance(e,dict) and not e.get("__null__"):
                    subs.append(ns(e["subject"]))
                else:
                    fb = sc.get(k); subs.append(ns(fb) if isinstance(fb,str) and fb.strip() else None)
            known = {s for s in subs if s}
            if len(known) < 2: continue
            n_rej += 1
            gset = {t.strip().rstrip(".").lower() for t in group}
            hn = bool(gset & new_texts); ho = bool(gset & old_texts)
            if hn and ho: n_hurt += 1
            elif hn: n_save += 1
    print(f"{backbone:<15}: clusters={n_c:>4} reject={100*n_rej/max(1,n_c):>5.1f}% save={n_save:>3} HURT={n_hurt:>3} predicted_delta={n_hurt-n_save:+d}")
```

**Report back**:每 backbone 的 (n_clusters, reject%, save, HURT, predicted_delta)。
